# Epilepsy Adaptive Trial Simulation

Monte Carlo comparison of a **traditional fixed-sample** epilepsy RCT versus an
**adaptive group-sequential** design (O'Brien-Fleming-style boundaries), using
realistic seizure diaries generated by the
[CHOCOLATE](https://github.com/GoldenholzLab/CHOCOLATE) simulator from the
Goldenholz Lab.

## What it does

For each simulated trial round, the script runs four trials:

| Design       | Mode          | Arms compared        |
|--------------|---------------|----------------------|
| Traditional  | Power         | drug vs placebo      |
| Traditional  | Type I error  | null vs null         |
| Adaptive     | Power         | drug vs placebo      |
| Adaptive     | Type I error  | null vs null         |

Key modeling choices:

- **Patients:** 40 weeks of seizure history per patient from CHOCOLATE's
  `simulator_base`; a random 8-week baseline + 12-week treatment window is
  drawn from it, producing natural regression to the mean.
- **Eligibility:** ≥ 4 seizures/month at baseline, plus a stability filter
  (≥ 4 of 8 weeks with a seizure; no single week > 50% of baseline seizures).
- **Drug effect:** per-patient efficacy ~ Beta(3, 7) (mean 30%).
- **Placebo effect:** per-patient efficacy ~ Beta(1.3, 18) (mean ≈ 7.7%).
- **Dropout:** 15%, not before day 14; percent change uses observed days.
- **Test:** Wilcoxon rank-sum on percent change in seizure rate.
- **Adaptive looks:** 50%, 75%, 100% of enrollment at nominal α = 0.005,
  0.02, 0.04.
- **Outputs:** power, Type I error, RR50, median percent change (MPC),
  average sample size, and stopping-look distribution, with a calibration
  check against published targets.

## Setup

```bash
git clone https://github.com/<your-username>/epilepsy-adaptive-trial-sim.git
cd epilepsy-adaptive-trial-sim
pip install -r requirements.txt
```

The CHOCOLATE repository is cloned automatically into `./CHOCOLATE` on first
run (requires `git`). It is not bundled here; see its repository for its
terms of use and citation.

## Running

```bash
python simulate_trials.py
```

Run from the repository root, since CHOCOLATE is located via a relative path.

Settings such as `N_PER_ARM`, `N_SIMULATIONS`, and the α boundaries are
global constants at the top of `simulate_trials.py`. The default of 100,000
simulations is computationally heavy; try a few hundred first.

### Resuming

Progress is checkpointed to `simulation_results.csv` every
`PROGRESS_INTERVAL` simulations. Re-running the script resumes from where it
stopped. Delete the CSV to start fresh, which is also necessary after
changing any parameters.
